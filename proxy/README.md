# Decent Proxy IP Sources
> Default `RAW` format: `protocol://ip:port` \
> `RAW List` URL's can be used with `px.sh` by `px -B -u <URL>` to cache into `/tmp/proxy.list`

> ### 1. [Proxifly GitHub]
> [Repo](https://github.com/proxifly/free-proxy-list) |
> [RAW List](https://raw.githubusercontent.com/proxifly/free-proxy-list/refs/heads/main/proxies/all/data.txt) (~4k)
>
> ### 2. [Proxiscrape]
> [Website](https://proxyscrape.com/free-proxy-list) |
> [RAW List](https://api.proxyscrape.com/v4/free-proxy-list/get?request=display_proxies&proxy_format=protocolipport&format=text)  (~2k)
